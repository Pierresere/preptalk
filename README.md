# PrepTalk

PrepTalk is an open-source, local-first interview-preparation app: a Node
server backed by a React UI, letting you practice with your choice of AI
provider using your own API keys.

## Getting started

```
npm install
```

Copy `server/.env.example` to `server/.env` and fill in at least one API key
(OpenAI, Anthropic, or Gemini).

```
npm run dev
```
